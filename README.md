# Developer Checklist

A practical collection of checklists for software developers.

This repository helps developers avoid common mistakes before shipping code, reviewing pull requests, or deploying applications.

## Included

- Frontend Checklist
- Backend Checklist
- Git Workflow Checklist
- Code Review Checklist
- Security Checklist
- Deployment Checklist

## Purpose

The goal of this repository is to provide reusable checklists that improve software quality and reduce production issues.

Contributions are welcome.
